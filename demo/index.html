createServer

Un wrapper para SSR + archivos estáticos

El framework expone createServer() para montar rutas, estáticos y metadata con una sola llamada. El demo server, en cambio, usa el serve() de Bun directamente: así el arranque del demo no depende de la API experimental.

  • Routing SSR: matchRoute() — estático y dinámico.
  • Archivos estáticos: resolveStaticFilePath() con isPathInside() para prevenir path traversal.
  • Metadata por ruta: title, description, og, stylesheets, inlineStyles, bodyStyle.
  • CORS: normalizeAllowedOrigins() canonicaliza y filtra wildcards inválidos.
  • Rate limiting: 100 req/min por IP, con pruning periódico.
import { createServer } from 'axiom-framework';

const server = createServer({
  routes: [
    { path: '/',    render: home },
    { path: '/ssr', render: ssrPage },
  ],
  staticDir: './public',
  cors: { origins: ['http://localhost:5173'] },
  rateLimit: { max: 100, windowMs: 60_000 },
});

server.listen(3000);

Tip: para las rutas SSR ejecuta bun run demo y abre http://localhost:3000.
