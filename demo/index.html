⚡ Axiom Demo Launcher

Dos flujos separados para evitar confusión: estático puro (abre directo) y SSR (requiere servidor).

🧱 Demo Estático Puro

No depende de rutas SSR. Puedes abrirlo como archivo local o servirlo con cualquier servidor estático.

Abrir static.html

🧪 Demo SSR (clásico)

Renderizado del lado servidor usando renderToString() con hydration markers (data-axiom-id). Solo funciona cuando el demo server está corriendo.

Abrir /ssr

🌀 Demo Streaming SSR (experimental)

Usa renderToReadableStream() (experimental) y emite el HTML como un ReadableStream en chunks. Ideal para progressive rendering y async boundaries futuras.

Abrir /ssr-stream

⚙️ createServer — server wrapper

El demo server usa createServer() (API experimental de axiom-framework) para integrar SSR + static files + per-route metadata + CORS + rate limiting en una sola llamada.

  • Routing SSR: matchRoute() en src/server.ts — soporta static + dynamic.
  • Static files: resolveStaticFilePath() con isPathInside() para prevenir path traversal.
  • Per-route metadata: title, description, og, stylesheets, inlineStyles, bodyStyle.
  • CORS: normalizeAllowedOrigins() — canonicaliza URLs, filtra wildcards inválidos.
  • Rate limiting: 100 req/min por IP, pruning periódico.

Tip: para SSR usa bun run demo y abre http://localhost:3000.
