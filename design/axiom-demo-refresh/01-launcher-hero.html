createServer

Un wrapper para SSR + archivos estáticos

Enruta, sirve estáticos y expone metadata por ruta con una sola llamada, con CORS normalizado y límite de peticiones por IP.

  • · Routing SSR con matchRoute() — estático y dinámico
  • · Archivos estáticos con resolveStaticFilePath() y isPathInside()
  • · Metadata por ruta: title, description, og, stylesheets
  • · CORS normalizado y rate limiting por IP
const server = createServer({
  routes: [
    { path: '/',      render: home },
    { path: '/ssr',   render: ssrPage },
  ],
  staticDir: './public',
  cors: { origins: ['http://localhost:5173'] },
  rateLimit: { max: 100, windowMs: 60_000 },
})

Tip: para las rutas SSR ejecuta bun run demo y abre http://localhost:3000.
